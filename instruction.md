## 1. Vision et Philosophie

### 1.1 Mission

**ChallengePact** transforme la discipline personnelle en aventure collective fun. La motivation vient de nos liens avec les autres + des mécaniques de jeu addictives.

### 1.2 Vision

Devenir LA référence des 16-25 ans pour améliorer leur vie : aussi addictif qu'un jeu mobile, aussi social qu'un groupe WhatsApp.

### 1.3 Valeurs

| Valeur | Description |
|--------|-------------|
| **Ensemble** | Réussir ou échouer ensemble. Entraide > compétition. |
| **Fun** | Le changement doit être amusant. Gamification intelligente. |
| **Authenticité** | Pas de filtres. Vrais efforts, même imparfaits. |
| **Engagement** | Promesse aux amis = sacrée. Le Pact matérialise ça. |
| **Récompense** | Chaque effort mérite reconnaissance. Petites victoires = grande motivation. |

### 1.4 Positionnement

```
         RÉSEAUX SOCIAUX (BeReal, Snapchat)
                    ↑
    JEUX MOBILES ←─ CHALLENGEPACT ─→ APPS D'HABITUDES
   (Candy Crush)    ↓                   (Habitica)
              JEUX SOCIAUX (Among Us)
```

On prend : pression sociale positive + mécaniques addictives + tracking utile + fun collectif.

## 2. Le Problème Résolu

### 2.1 Constat

Les 16-25 ans veulent changer mais n'y arrivent pas. Les apps d'habitudes sont :
- Trop sérieuses/ennuyeuses
- Trop solitaires
- Trop faciles à abandonner
- Pas assez rewarding

### 2.2 Solutions ChallengePact

| Cause | Notre solution |
|-------|----------------|
| Pas d'accountability | Les amis comptent sur toi |
| Gratification différée | Récompenses immédiates (roue, XP, cartes) |
| Isolement | Groupe qui voit tout |
| Pas de fun | Gamification complète |
| Pas de conséquences | Gages, mascotte triste, pression sociale |

### 2.3 Insight Clé

> **"On ne laisse pas tomber ses amis + On adore gagner des récompenses"**

---

## 3. La Solution ChallengePact

### 3.1 Concept

**App de défis entre amis avec validation quotidienne obligatoire + mécaniques de jeu (cartes, roue, mascotte, titres) pour une expérience addictive et fun.**

### 3.2 Les 4 Piliers

1. **Engagement Collectif (Pact)** : 1 membre rate = tout le groupe perd
2. **Preuve Quotidienne (Check-in)** : Photo/vidéo/texte avec timestamp
3. **Cercle Restreint (Squad)** : 2-6 personnes qui se connaissent + mascotte commune
4. **Gamification** : Roue, cartes, XP, niveaux, titres, cosmétiques, ligues

### 3.3 Boucle d'Engagement

```
RÉVEIL → ACTION → CHECK-IN → ROUE → RÉCOMPENSE → SOCIAL → MASCOTTE
  ↓         ↓         ↓         ↓         ↓          ↓         ↓
Notif    Sport    Photo    Spin!    +XP/carte   Kudos    Elle grandit
Mini-défi                                       Réactions
```

## 4. Mécaniques de Jeu Core

### 4.1 Création de Défi

| Paramètre | Options | Défaut |
|-----------|---------|--------|
| Nom | Texte (50 car.) | - |
| Description | Texte (500 car.) | - |
| Emoji | 100+ choix | 🎯 |
| Durée | 7/14/21/30 jours | 21j |
| Preuve | Photo/Vidéo/Texte/Check | Photo |
| Heure limite | 00h-23h59 | 23h59 |
| Jours actifs | Tous/Semaine/WE/Custom | Tous |
| Mode | Strict/Tolérant | Tolérant |
| Gages | Oui/Non | Non |
| Ligue Hardcore | Oui/Non | Non |
| Mascotte | 10 choix | Vote groupe |

### 4.2 Système d'Invitation

- Lien unique partageable
- Partage natif (WhatsApp, iMessage, Instagram, Snapchat, Discord)
- QR Code
- Username
- Contacts

**Contraintes** : Min 2, Max 6 participants. Une fois démarré, fermé.

### 4.3 Cycle Quotidien

```
00:00 ─ Nouveau jour, Mini-Défi généré, Mascotte se réveille
08:00 ─ Rappel matinal + Mini-Défi affiché
  ↓
[USER FAIT SON ACTION IRL]
  ↓
??:?? ─ CHECK-IN
        → Photo/vidéo/texte
        → +XP de base
        → Bonus Mini-Défi (si accompli)
        → SPIN ROUE DE LA FORTUNE
        → Mascotte réagit
        → Notif aux autres
  ↓
21:59 ─ Rappel 2h avant (si pas validé) + Nudges possibles
23:29 ─ Rappel URGENT 30min + Mascotte stressée
23:59 ─ DEADLINE
        → Tous validé : Streak +1, Mascotte heureuse
        → Quelqu'un manque :
          - STRICT : Fin du défi, Gages activés
          - TOLÉRANT : Vie -1, si 0 vies → Fin
```

### 4.4 Fin de Défi

**Victoire 🎉**
- Animation épique (confettis, feux d'artifice)
- Badge + XP bonus massif + Carte rare garantie
- Mascotte forme finale
- Story partageable
- Proposition nouveau défi

**Échec 😢**
- Message encourageant (pas culpabilisant)
- Rappel des gages (si activés)
- Stats du parcours
- Proposition de recommencer
- Note : responsable NON désigné publiquement

## 9. Paris et Gages

### 9.1 Concept

Au lancement, définir des gages pour qui fait échouer le groupe. Pression sociale fun.

### 9.2 Activation

Option à la création du défi : "Activer les gages ?"

### 9.3 Définition

Chaque participant propose son gage :
- Texte libre OU
- Suggestions : 🍺 Tournée, 🧹 Ménage, 🎤 Karaoké, 🤡 Costume, 💇 Coiffure, 📱 Story embarrassante

### 9.4 Validation Collective

Avant le début, tous voient et valident les gages de chacun.

### 9.5 Exécution

En cas d'échec :
1. App identifie le responsable (en privé)
2. Rappelle son gage
3. 7 jours pour poster preuve
4. Groupe notifié quand accompli
5. Si non fait : "gage non honoré" visible

**Important** : Le responsable n'est PAS désigné publiquement → évite blâme toxique.

## 14. Mode Hardcore et Ligues

### 14.1 Concept

Pour les compétitifs : inscrire son groupe dans une ligue et se mesurer à d'autres.

### 14.2 Règles Hardcore

- Mode Strict obligatoire
- Pas de cartes de protection utilisables
- XP x1.5 sur tout le défi
- Classement entre groupes

### 14.3 Matchmaking

Groupes placés ensemble selon :
- Même template
- Même durée
- Même date de début
- ~50-100 groupes par ligue

### 14.4 Scoring

| Critère | Points |
|---------|--------|
| Jour validé tous | +100 |
| Moyenne avant midi | +20 |
| Tous avant 18h | +30 |
| Streak parfaits | +10/jour |
| Synchro (même heure) | +50 |

### 14.5 Élimination

1 jour raté = éliminé du classement (peut continuer le défi).

- Stats collectives (défis ensemble, taux réussite, chimie)

### 16.2 Réactions

🔥 Fire, ❤️ Cœur, 😂 Rire, 😮 Wow, 💪 Force, 👏 Clap, 🤯 Mind blown + emojis débloqués.

### 16.3 Commentaires

Sous chaque preuve. Mentions @username. GIFs.

### 16.4 Chat de Groupe

Conversation intégrée. Notifs configurables. Photos/GIFs.

### 16.5 Nudges

Si quelqu'un n'a pas validé : envoyer notification push spéciale (max 3/jour/personne).

### 16.6 Amis

Ajouter via username, lien, contacts, QR. Voir niveau, badges, titres, défis en cours.

### 16.7 Anti-Toxicité

❌ PAS de : Classement global public, followers visibles, fil d'inconnus, commentaires hors squad, désignation publique du responsable d'échec, DMs avec inconnus.

## Annexe : Design Guidelines

### Ton de Voix

- **Friendly** : Pote qui encourage
- **Fun** : Emojis, expressions jeunes
- **Positif** : Focus progrès, jamais culpabilisant
- **Direct** : Messages courts
- **Inclusif** : Parler à tous

### Exemples Copywriting

| Contexte | ❌ Éviter | ✅ Faire |
|----------|----------|---------|
| Rappel | "Vous n'avez pas validé" | "Plus que 2h, tu gères ! 💪" |
| Échec | "Vous avez échoué" | "Ce n'est que partie remise ! 🔄" |
| Succès | "Défi terminé" | "VOUS AVEZ TOUT DÉCHIRÉ ! 🎉🔥" |
| Roue | "Tourner" | "SPIN POUR GAGNER ! 🎰" |

### Identité Visuelle

- **Principal** : Violet #7C3AED
- **Secondaire** : Orange #F97316
- **Succès** : Vert #10B981
- **Alerte** : Rouge #EF4444
- **Typo** : Sans-serif arrondie (Nunito/Poppins)
- **Icônes** : Filled, coins arrondis
- **Illustrations** : Flat moderne, personnages divers
- **Animations** : Micro-interactions satisfaisantes, célébrations joyeuses

### UX Principles

1. **Instant gratification** : Récompense immédiate
2. **Low friction** : Minimum de clics
3. **Social proof** : Montrer les autres
4. **Progress visibility** : Barres, compteurs partout
5. **Delightful moments** : Surprises, sons satisfaisants
6. **FOMO** : Events limités, streaks à perdre
7. **Ownership** : Collection, personnalisation
